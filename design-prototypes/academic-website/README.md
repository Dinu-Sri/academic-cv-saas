# Academic Website Prototype

An isolated HTML/CSS/JavaScript design lab for the CVScholar academic website. It is not imported by the PHP application or the Next.js rewrite.

## Pages

- `index.html` - rich-profile homepage and one-screen academic snapshot
- `research.html` - research interests, projects, grants, patents, and filterable publications
- `journey.html` - appointments, experience, education, teaching, supervision, skills, and languages
- `contributions.html` - talks, conferences, service, editorial work, awards, and memberships
- `contact.html` - compact accessible enquiry form
- `sparse.html` - sparse-profile composition with thin categories merged into Home
- `system.html` - design principles, visual tokens, typography, and component samples

Open `index.html` directly in a browser. All pages use relative assets and require no server, build, dependency, database, or environment variable.

## Editing

- Change demo content in `data.js`.
- Change page composition and rendering in `app.js`.
- Change all visual tokens and responsive behavior in `styles.css`.

The contact form is deliberately non-operational. Links and identifiers are representative demo content only.
