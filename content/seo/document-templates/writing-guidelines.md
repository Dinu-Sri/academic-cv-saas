# CVScholar Article Writing Guidelines
## Based on Koray Tuğberk GÜBÜR's Algorithmic Authorship Framework

These guidelines govern how every CVScholar blog article is written, structured, and optimized. They are derived from the Holistic SEO methodology — specifically Algorithmic Authorship (AA), Entity-Attribute-Value (EAV) coverage, and Semantic Content Network principles.

---

## 1. Macro Context — One Topic Per Page

Every article has exactly **one macro context** — the single primary topic the page covers.

- The H1 heading defines the macro context
- Every H2, H3, paragraph, and entity mention must serve the macro context
- Do not combine unrelated topics on one page
- Define user intent (informational, procedural, comparison) before writing

**Example macro context:** "How to Write an Academic CV"
- Valid H2: "What Are the Essential Sections of an Academic CV?"
- Invalid H2: "Best Resume Templates for Tech Jobs" (different macro context)

---

## 2. Heading Hierarchy

### Structure Rules
- **Exactly one H1 per page** — contains the central entity and primary query terms
- **Never skip heading levels** — H1 → H2 → H3 → H4 (never H1 → H3)
- **H2s must be formatted as user questions** — match how users search
- **Every heading must accurately describe the content beneath it**
- **Avoid generic headings** — never use "Introduction," "Overview," or "Conclusion" as H2s

### H2 Format (Question-Based)
```
✓ "What Are the Essential Sections of an Academic CV?"
✓ "How Do You Format Publications on an Academic CV?"
✓ "What Mistakes Do Early-Career Researchers Make on Academic CVs?"

✗ "Essential Sections"
✗ "Publication Formatting"
✗ "Common Mistakes"
```

---

## 3. Answer Zone — 40-Word Extractive Answer

Immediately after each H2, provide a **concise 40-word extractive answer** that directly responds to the heading question. This is the passage search engines extract for featured snippets.

### Rules
- 40 words (±10), declarative, factual
- Must contain the central entity + key attribute mentions
- Placed immediately after the H2, before any elaboration
- No filler phrases, no delayed answers

### Example
```
## What Is an Academic CV?

An academic CV is a comprehensive document that presents a researcher's complete scholarly history, including publications, teaching experience, grants, and awards. Academic CVs have no page limit and grow throughout an academic career. (35 words)

[Elaboration paragraphs follow...]
```

## 4. Sentence-Level Rules

### 4.1 Be Certain — Eliminate Hedging
Replace hedging verbs ("should," "might," "could," "may want to") with factual declarative statements.

```
✓ "An academic CV includes all publications, presentations, and grants."
✗ "An academic CV should probably include your publications and other items."
```

### 4.2 Use Short Sentences
Short sentences reduce ambiguity for readers and NLP models. Avoid nested clauses. One idea per sentence.

```
✓ "Contact information appears first. Include your institutional affiliation, email, and ORCID link."
✗ "When you are thinking about what to put at the top of your CV, which is something that many people often wonder about, you should consider including your contact information along with your institutional affiliation."
```

### 4.3 Declaration First
Start sentences with the primary declaration. Place qualifiers and conditions after the main statement.

```
✓ "Reverse chronological order is the standard for listing publications."
✗ "When considering the various approaches that scholars have debated over the years, it becomes clear that reverse chronological order is generally the standard."
```

### 4.4 Avoid Starting with "If"
Sentences starting with "if" delay the main declaration. Place the declaration first, then add the condition.

```
✓ "Content configuration is required when semantic distances change after a core update."
✗ "If semantic distances change after a core update, content configuration is required."
```

### 4.5 Optimize First Words of Paragraphs
The first words of each paragraph carry disproportionate semantic weight. Start with informative, contextually relevant terms.

```
✓ "Publication formatting follows discipline-specific citation standards."
✗ "It is also worth noting that publication formatting follows discipline-specific citation standards."
```

---

## 5. Word Choice & Lexical Semantics

### 5.1 Contextual Relevance
Every word in a paragraph must have contextual relevance to the section's topic. Off-topic vocabulary dilutes the semantic signal.

```
In a paragraph about academic publications:
✓ "peer-reviewed," "journal," "citation," "DOI," "impact factor," "authorship"
✗ "investment," "download," "architecture" (without semantic justification)
```

### 5.2 Use Numeric Values — Not Vague Quantities
Use specific numbers, percentages, or exact quantities. Precision signals expert-level knowledge.

```
✓ "An academic CV contains 7 essential sections."
✗ "An academic CV contains several important sections."
```

### 5.3 Give Examples After Plural Amounts
When stating a plural count, provide specific examples immediately.

```
✓ "There are 6 common CV mistakes, such as inconsistent formatting, missing DOI links, and padding with trivial items."
✗ "There are 6 common CV mistakes." (no examples)
```

### 5.4 Verb Context Matching
Verbs carry contextual meaning and disambiguate entities. Use verbs that signal the correct semantic domain.

```
Academic context: "publish," "present," "review," "cite," "defend," "supervise"
Business context: "market," "sell," "acquire," "invest"
```

### 5.5 Cut Contextless Words
Remove words with no semantic weight: "basically," "actually," "in order to," "it is important to note that," "as a matter of fact," "needless to say"

### 5.6 Vocabulary Control
- Use **consistent terminology** — pick one term and stick with it (e.g., "academic CV" not alternating with "academic curriculum vitae" and "scholarly resume" randomly)
- Use **synonyms purposefully** — introduce synonyms for entity recognition, not for variety
- Use **hypernyms/hyponyms** correctly — "publication" (hypernym) → "journal article," "book chapter," "conference paper" (hyponyms)

## 6. Entity-Attribute-Value Coverage

### 6.1 Define Every Entity You Mention
Mentioning an entity is not coverage. You must define it within the content.

```
✓ "An ORCID identifier is a persistent digital identifier that distinguishes individual researchers and connects them to their scholarly contributions."
✗ "Make sure to add your ORCID to your CV." (undefined entity)
```

### 6.2 Connect Entities Through Relationships
Use predicates that explain how Entity A relates to Entity B.

```
✓ "The publications section demonstrates research productivity, which search committees evaluate alongside teaching experience and grant funding."
✗ "Publications, teaching, and grants are important." (co-mentioned, not connected)
```

### 6.3 Cover Attributes and Values
For each entity, identify and cover its attributes (properties) and values (specific data).

**Central Entity: Academic CV**
| Attribute | Value |
|-----------|-------|
| Purpose | Document scholarly career for evaluation |
| Key Sections | Publications, Education, Teaching, Grants, Awards, Service, Skills |
| Formatting | Reverse chronological, consistent citation style, no page limit |
| Career Stages | Undergraduate, Graduate, Postdoc, Junior Faculty, Senior Faculty |
| Evaluation Criteria | Research productivity, teaching effectiveness, service contribution |

### 6.4 Use Factual Information Over Opinion
Experts provide facts, definitions, and data — not speculation.

```
✓ "Search committees review an average of 50-200 applications per faculty position."
✗ "I think search committees probably look at a lot of applications."
```

## 7. Content Structure & Flow

### 7.1 Linear Contextual Flow
Content flows from broad to specific: Definition → Components → How it works → Examples → Related concepts.

### 7.2 Complete Context Within Paragraphs
A single context (definition, explanation, argument) must be completed within one paragraph. Do not split across paragraphs.

### 7.3 Contextual Bridges Between Sections
When transitioning between sections, use a bridge sentence that connects the previous topic to the next.

```
"With the essential sections defined, the next step is formatting each section for maximum readability and impact."
```

### 7.4 Separate Main Content from Supplementary
- **Main content** processes the macro context with all context terms and main entities
- **Supplementary content** touches micro contexts and provides internal links to side topics
- Internal links to related but different topics belong in supplementary sections

### 7.5 Contextual Borders
The transition from main content to supplementary content (e.g., the CTA section) must be gradual, not abrupt.

---

## 8. Internal Linking Rules

### 8.1 Hub-and-Spoke Model
- Pillar articles (hubs) link to cluster articles (spokes)
- Cluster articles link back to the pillar hub
- Related cluster articles cross-link to each other

### 8.2 Anchor Text Rules
- **Match anchor text to target page title** — anchor text must contain the central entity
- **Never use generic anchors** — no "click here," "read more," "learn more"
- **Ground anchors in entities/attributes** — anchor text carries semantic weight

```
✓ <a href="...">academic CV publications section guide</a>
✗ <a href="...">click here for more info</a>
```

### 8.3 Placement
- 1-2 contextual internal links per 300 words in main content
- Additional supplementary links in the CTA/related section
- At least 1 link to the pillar article
- At least 2 links to related cluster articles

## 9. Typography & Formatting Signals

### 9.1 Bold the Answer — Not the Keyword
Bold formatting signals which part of the content is the answer.

```
✓ "The 3 essential font choices for academic CVs are **Computer Modern, Times New Roman, and Garamond**."
✗ "The **3 essential font choices** for academic CVs are Computer Modern, Times New Roman, and Garamond."
```

### 9.2 Consistent List POS Tags
Start each list item with the same part of speech.

```
✓ All verbs:
- Include your institutional affiliation
- List degrees in reverse chronological order
- Organize publications by type
- Add DOI links to each publication

✗ Mixed POS:
- Your institutional affiliation
- List degrees in reverse chronological order
- Good organization of publications
- You should add DOI links
```

### 9.3 Tables for Comparisons
Use tables when presenting structured data, comparisons, or attribute-value pairs.

## 10. Content Quality Rules

### 10.1 No Rhetoric Without Information
Every sentence must carry informational value. No rhetorical questions, generic motivational statements, or vague introductions.

```
✗ "Have you ever wondered what makes a great academic CV? In today's competitive academic landscape, having a well-crafted CV is more important than ever..."
✓ "An academic CV contains 7 core sections: contact information, education, publications, teaching, grants, awards, and service."
```

### 10.2 Cite Sources and Authorities
Cite the source or authority before making a claim.

```
✓ "According to the American Psychological Association, CVs for academic positions follow the reverse chronological format."
✗ "Most people agree that reverse chronological order is best."
```

### 10.3 No AI Content Patterns
Avoid patterns that signal machine-generated content:
- Overuse of transitional phrases ("furthermore," "moreover," "in addition")
- Generic statements without specific numbers or sources
- Repetitive sentence structures across paragraphs
- Lack of expert vocabulary or cited authorities

### 10.4 No Dash Explanations
Never use em dashes (—) or hyphens (-) as inline explanatory separators. This `**Bold** — explanation` or `**Bold** - explanation` pattern is a well-known AI writing signature. Use commas, colons, or restructured sentences instead.

```
✗ **Research productivity** — peer-reviewed publications, conference presentations, funded grants
✗ **Research productivity** - peer-reviewed publications, conference presentations, funded grants
✓ **Research productivity**, including peer-reviewed publications, conference presentations, and funded grants
✓ **Research productivity**: peer-reviewed publications, conference presentations, and funded grants

✗ ORCID — a persistent digital identifier that distinguishes researchers
✓ ORCID, a persistent digital identifier that distinguishes researchers

✗ Google Scholar profile URL — enables search committees to verify citation counts
✓ Google Scholar profile URL, which enables search committees to verify citation counts
```

This rule applies everywhere: list items, inline parentheticals, definitions, and section intros. If a sentence uses a dash to introduce an explanation, rewrite it with a comma or a subordinate clause.

### 10.5 Content Configuration (Revision)
After initial publication, revise content for:
- Missing entities or attributes
- Vocabulary gaps compared to competing documents
- Broken context flow
- Non-accurate information
- Broken sentence structures

## 13. Pre-Publication Checklist

### Structure
- [ ] Single macro context confirmed
- [ ] User intent defined (informational / procedural / comparison)
- [ ] Exactly one H1 with central entity
- [ ] All H2s formatted as user questions
- [ ] Heading hierarchy: H1 → H2 → H3 (no skipping)
- [ ] 40-word extractive answer below each H2

### Entity Coverage
- [ ] All mentioned entities are defined
- [ ] Entities are connected through predicates
- [ ] EAV coverage is complete for central entity
- [ ] Facts cited with sources — no unsupported opinions

### Sentence Quality
- [ ] Short sentences with declarations first
- [ ] Hedging verbs eliminated
- [ ] Contextless filler words removed
- [ ] No context broken across paragraphs
- [ ] First words of paragraphs are informative
- [ ] Verb context matches semantic domain
- [ ] Numeric values used (not vague quantities)
- [ ] Examples provided after plural amounts

### Formatting
- [ ] Bold applied to answers, not keywords
- [ ] List items use consistent POS tags
- [ ] Tables used for structured comparisons
- [ ] Content is skimmable with clear visual hierarchy

### Linking
- [ ] Internal links follow hub-and-spoke model
- [ ] Anchor text matches target page titles
- [ ] At least 1 link to pillar article
- [ ] At least 2 links to related cluster articles
- [ ] No generic anchor text ("click here")

### SEO
- [ ] Primary keyword in H1, first 100 words, meta description
- [ ] Meta description under 160 characters
- [ ] Structured data implemented (Article, Breadcrumbs)
- [ ] Page connected to semantic content network

### Quality
- [ ] AI-generated content patterns eliminated
- [ ] No rhetorical questions without information
- [ ] Contextual flow is linear (macro → micro)
- [ ] Contextual bridges between all sections
- [ ] Expert-level domain vocabulary used throughout
