# Publishing Order — Phase 1 (First 50 Articles)

Central entity: **Academic CV**
Goal: Build topical authority from core pillar content outward.

## Publishing Strategy
1. Start with pillar/foundational articles (most link-worthy)
2. Publish cluster articles that support each pillar
3. Interlink every article to pillar + 2-3 related cluster articles
4. Maintain 2-3 articles per week cadence
